# Как поставить приложение «РЖЯ» на iPhone с Windows

Без Mac, без App Store и без платного аккаунта разработчика. Нужны компьютер с
Windows, iPhone, кабель и обычный Apple ID.

Коротко, что происходит:

1. GitHub собирает файл приложения `RSL.ipa`. Он без подписи, и iPhone такой
   файл не примет.
2. Программа Sideloadly на Windows подписывает его вашим Apple ID и ставит на
   телефон.
3. Подпись бесплатного Apple ID действует 7 дней. Потом приложение перестаёт
   открываться, и его нужно подписать заново (данные при этом сохраняются).

Первый раз всё займёт около получаса. Потом — пара минут раз в неделю.

Приложение рассчитано на iPhone и iPad с iOS 17 и новее.

---

## 1. Скачать RSL.ipa с GitHub

Нужно войти в свой аккаунт GitHub: без входа файлы сборок не скачиваются.

1. Откройте <https://github.com/dimakhk/rsl/actions>.
2. Слева выберите **iOS app (.ipa)**.
3. В списке справа нажмите на верхнюю строку с зелёной галочкой ✅.
   Жёлтый кружок значит, что сборка ещё идёт (15–20 минут), красный крест —
   что она не удалась.
4. Прокрутите страницу вниз до раздела **Artifacts** и нажмите **RSL-ipa**.
   Скачается архив `RSL-ipa.zip` (около 45 МБ).
5. Распакуйте архив: правой кнопкой → «Извлечь все…». Внутри лежит `RSL.ipa`.
   Сам `RSL.ipa` распаковывать не нужно.

Сборки хранятся 30 дней. Если список пуст или сборка устарела, запустите новую:
на той же странице кнопка **Run workflow** → в поле **Branch** выберите ветку →
**Run workflow**. Через 20 минут обновите страницу.

> Кнопка **Run workflow** появится после того, как изменения попадут в ветку
> `main`. До этого сборка запускается сама при отправке изменений в ветку `ios`.

На той же странице сборки, в **Artifacts**, лежит архив **screenshots**: снимки
всех экранов приложения из симулятора iPhone.

## 2. Что установить на Windows (один раз)

Sideloadly работает только с версиями iTunes и iCloud **с сайта Apple**, не из
Microsoft Store.

1. Проверьте, нет ли у вас версий из магазина: «Параметры» → «Приложения» →
   «Установленные приложения», в поиске наберите `iTunes`, потом `iCloud`.
   Если что-то нашлось и рядом написано Microsoft Store — удалите.
2. Установите iTunes с сайта Apple:
   <https://www.apple.com/itunes/download/win64>
3. Установите iCloud с сайта Apple:
   <https://updates.cdn-apple.com/2020/windows/001-39935-20200911-1A70AA56-F448-11EA-8CC0-99D41950005E/iCloudSetup.exe>
   Входить в iCloud после установки не обязательно.
4. Перезагрузите компьютер.
5. Установите Sideloadly: <https://sideloadly.io/> → **Download** → Windows
   64-bit (прямая ссылка: <https://sideloadly.io/SideloadlySetup64.exe>).

## 3. Подключить iPhone

1. Подключите iPhone кабелем и разблокируйте его.
2. На телефоне появится вопрос «Доверять этому компьютеру?» → **Доверять** →
   введите код-пароль телефона.
3. Откройте iTunes и убедитесь, что вверху слева появился значок телефона.
   Если значка нет, Sideloadly телефон тоже не увидит (см. «Частые ошибки»).
   После этого iTunes можно закрыть.

## 4. Установить приложение

1. Запустите Sideloadly.
2. В поле **iDevice** должен быть ваш iPhone.
3. Перетащите `RSL.ipa` в окно Sideloadly, на большой значок **IPA** слева.
4. В поле **Apple ID** введите почту своего Apple ID.
5. Оставьте галочку **Automatic app refresh**, если она есть (о ней в разделе 6).
6. Нажмите **Start**.
7. Sideloadly спросит пароль Apple ID, а потом код подтверждения, который
   придёт на ваши устройства Apple. Введите их.
8. Дождитесь надписи **Done.** в нижней строке. На телефоне появится значок
   «РЖЯ». Открывать его пока рано — сначала разделы 5.1 и 5.2.

**Про пароль.** Sideloadly передаёт Apple ID и пароль только серверам Apple —
так написано у них на сайте, и программой пользуются много лет. Но это
сторонняя программа, и проверить это сам я не могу. Самый спокойный вариант —
завести для установки отдельный Apple ID: <https://account.apple.com/>.
Он бесплатный, и на телефоне в него входить не нужно.

## 5. Разрешить запуск на iPhone (один раз)

### 5.1. Доверие разработчику

«Настройки» → «Основные» → «VPN и управление устройством» → в разделе
«ПО разработчика» нажмите на свой Apple ID → **Доверять «…»** → **Доверять**.

Телефону в этот момент нужен интернет.

### 5.2. Режим разработчика (iOS 16 и новее)

«Настройки» → «Конфиденциальность и безопасность» → прокрутите в самый низ →
«Режим разработчика» → включить → **Перезагрузить**.

После перезагрузки разблокируйте телефон, появится окно «Включить режим
разработчика?» → **Включить** → введите код-пароль.

Пункта «Режим разработчика» нет в настройках, пока на телефон ни разу не
ставили приложение через компьютер. Если его нет — сначала выполните раздел 4,
потом вернитесь сюда.

### 5.3. Первый запуск

Откройте «РЖЯ», нажмите кнопку с ладонью и разрешите доступ к камере.
Кнопка с микрофоном при первом нажатии спросит доступ к микрофону и к
распознаванию речи — их тоже нужно разрешить.

## 6. Через 7 дней: продлить подпись

Когда подпись истечёт, приложение перестанет открываться (значок останется).
Удалять его не нужно.

**Самый простой способ — автоматический.** Если при установке стояла галочка
**Automatic app refresh**, Sideloadly сам переподписывает приложение за пару
дней до срока. Для этого нужно, чтобы:

- компьютер был включён, а Sideloadly запущен (он сидит в трее возле часов);
- телефон был подключён кабелем **или** находился в той же сети Wi-Fi с
  включённым экраном.

Чтобы работало по Wi-Fi, один раз включите синхронизацию: подключите телефон
кабелем → iTunes → значок телефона → «Обзор» → «Параметры» → галочка
**«Синхронизировать с этим iPhone по Wi-Fi»** → «Применить».

**Вручную.** Повторите раздел 4 с тем же файлом `RSL.ipa` и тем же Apple ID.
Приложение установится поверх старого. Разделы 2, 3 и 5 повторять не нужно.

Обновление приложения делается так же: скачайте новый `RSL.ipa` (раздел 1) и
повторите раздел 4.

## 7. Ограничения бесплатного Apple ID

- Подпись действует **7 дней**.
- На одном устройстве одновременно работают не больше **3 приложений**,
  установленных таким способом.
- Не больше **10 новых идентификаторов приложений за 7 дней**. Если
  переустанавливать одно и то же приложение, лимит не тратится.
- Нет push-уведомлений, iCloud и покупок внутри приложения. «РЖЯ» ими не
  пользуется.
- Платный аккаунт (99 $ в год) продлевает подпись до года и снимает лимит на
  3 приложения. Для «РЖЯ» он не обязателен.

## 8. Частые ошибки

| Что видно | Что делать |
|---|---|
| В Sideloadly в поле iDevice пусто или `no devices detected` | Удалить iTunes и iCloud из Microsoft Store, поставить с сайта Apple (раздел 2), перезагрузить компьютер. Открыть iTunes при подключённом телефоне и нажать «Доверять» на телефоне. Попробовать другой кабель или порт USB. |
| `Developer Mode Required` или приложение не открывается сразу после установки | Раздел 5.2. |
| «Ненадёжный разработчик» при открытии | Раздел 5.1. |
| «Не удалось проверить приложение» / «Целостность не удалось проверить» | Прошло 7 дней — раздел 6. Если только что установили: включите на телефоне интернет и повторите раздел 5.1. |
| `Guru Meditation … maximum number of apps` или ошибка про `3 apps` | На телефоне уже три приложения, поставленных так же. Удалите одно. |
| `maximum number of App IDs` | Исчерпан лимит в 10 идентификаторов за неделю. Подождать 7 дней или взять другой Apple ID. |
| Ошибка входа, `Incorrect Apple ID or password`, не приходит код | Проверьте почту и пароль на <https://account.apple.com/>. У Apple ID должна быть включена двухфакторная аутентификация. |
| Ошибка со словом `anisette` или вход зависает | Переустановите iCloud с сайта Apple (раздел 2). Если не помогло: **Advanced Options** → **Anisette authentication** → **Remote anisette**. |
| Установка прошла, а значка на экране нет | Перезагрузите телефон. |
| Камера в приложении не открывается | «Настройки» → «РЖЯ» → включить «Камера». |
| Кнопка с микрофоном сразу отжимается | «Настройки» → «РЖЯ» → включить «Микрофон» и «Распознавание речи». |
| Озвучки не слышно | Проверьте громкость и что значок звука вверху не перечёркнут. Русские голоса: «Настройки» → «Универсальный доступ» → «Устный контент» → «Голоса» → «Русский». |
| Красный крест у сборки на GitHub | Нажмите на эту сборку: вверху страницы будет текст ошибки. Пришлите его тому, кто ведёт проект. |

## 9. Что нужно для распознавания

Жесты распознаются одним из двух способов, приложение выбирает само:

- **На сервере** (точнее). Нужен интернет и включённый сервер. Адрес сервера
  приложение берёт из файла `server.json` на сайте, а если сайт недоступен —
  из копии внутри себя.
- **В самом телефоне** (без интернета), когда сервер не отвечает. После запуска
  приложение сравнивает два способа считать — процессор и Core ML — и
  оставляет тот, что быстрее; первые секунды распознавание может идти медленнее.

Показывать жесты нужно по одному, с короткой паузой между ними: слитную фразу
модели не разбирают.

Как проверить распознавание без интернета: включите авиарежим, откройте
приложение, нажмите кнопку с ладонью и покажите жест. Если слова появляются —
работает.

Как посмотреть, чем и с какой скоростью считает приложение: трижды быстро
нажмите на название чата вверху экрана. Появится чёрная табличка: три лучших
варианта модели, «сервер» или «устройство», кадров в секунду и миллисекунды
на одно распознавание. Ещё три нажатия её убирают.

## 10. AltStore вместо Sideloadly

AltStore делает то же самое, но устроен сложнее: на компьютер ставится
AltServer, он ставит на телефон приложение AltStore, а уже оно ставит
`RSL.ipa`. Плюс в том, что продлевать подпись можно с телефона, когда он в
одной сети Wi-Fi с компьютером. Минус — AltStore сам занимает одно из трёх
мест. Требования те же: iTunes и iCloud с сайта Apple. Сайт:
<https://altstore.io/>. Если Sideloadly работает, менять его незачем.
